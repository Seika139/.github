# .github

## Code Review Rules

- Write review comments in Japanese.
- Report only concrete, actionable defects supported by the code and available repository context.
- For each defect, explain the evidence and the concrete failure scenario.
- For important issues outside the scope of the pull request, suggest creating a separate issue.

## Terraform Rules

Terraform 配下の設定、state、または実行タスクを変更・操作するときは、[terraform-operations skill](.agents/skills/terraform-operations/SKILL.md) を読みます。HCP workspace の設定、state 移行、実行環境の接続では、あわせて [README.md の HCP Terraform 手順](README.md) に従います。
